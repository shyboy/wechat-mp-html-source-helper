# WeChat MP HTML Source Helper

微信公众号 HTML 源码助手

一个面向微信公众号后台编辑器的 Chrome 扩展。

它会在 `mp.weixin.qq.com` 图文编辑页注入一个 `HTML 源码` 按钮，方便你把现成的 HTML 片段直接导入到微信编辑器里，也可以反向读取当前编辑区的 HTML 做调试或备份。

## 功能特性

- 在微信公众号后台编辑器工具栏中增加 `HTML 源码` 按钮
- 如果工具栏挂载失败，自动降级为右下角悬浮按钮
- 支持粘贴 HTML 并一键写入正文编辑区
- 支持读取当前图文正文的 HTML
- 导入时会做基础安全清洗，移除高风险标签和内联事件
- 自动触发编辑器常见输入事件，尽量让微信后台识别内容变更

## 适用场景

- 将已有网页片段快速导入公众号图文
- 从其他编辑器迁移部分内容到微信后台
- 调试公众号编辑器对 HTML 的兼容表现
- 读取当前正文源码做备份、比对或二次处理

## 安装方式

当前项目为未上架 Chrome Web Store 的本地扩展，推荐通过开发者模式加载。

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 打开右上角的 `开发者模式`
3. 点击 `加载已解压的扩展程序`
4. 选择当前项目目录：

```text
wechat-html-source-extension
```

5. 加载完成后，进入微信公众号后台图文编辑页面测试

## 使用说明

1. 打开微信公众号后台图文编辑页面，域名应为 `https://mp.weixin.qq.com/`
2. 在编辑器工具栏中找到 `HTML 源码` 按钮
3. 点击按钮后，在弹窗中粘贴 HTML 内容
4. 点击 `导入并预览`，内容会写入当前正文编辑区
5. 如果需要查看当前正文源码，点击 `读取当前 HTML`

## 安全处理

为了降低直接注入 HTML 带来的风险，扩展在导入前会做一层基础清洗：

- 删除 `script`
- 删除 `iframe`
- 删除 `object`
- 删除 `embed`
- 删除 `base`
- 删除带有 `http-equiv="refresh"` 的 `meta`
- 删除所有形如 `onclick`、`onload` 的内联事件属性

这只是基础过滤，不等于完整的 HTML 安全沙箱。

## 已知限制

- 微信公众号后台编辑器本身会再次清洗标签、属性和样式，因此最终渲染结果可能与原始 HTML 不完全一致
- 不保证复杂布局、外链脚本、嵌入式组件能够被微信编辑器保留
- 微信后台改版后，工具栏选择器可能失效；当前代码已提供悬浮按钮作为兜底入口
- 扩展目前仅针对 `mp.weixin.qq.com` 页面生效

## 开发说明

这是一个 Manifest V3 扩展，当前通过 `content_scripts` 注入脚本和样式，不依赖后台服务、构建工具或第三方包。

如果你要继续开发，通常只需要：

1. 修改 `content.js`
2. 修改 `styles.css`
3. 回到 `chrome://extensions/` 点击刷新扩展
4. 重新打开或刷新公众号编辑页面验证效果

## 权限与作用范围

当前扩展只声明并匹配：

```json
"matches": ["https://mp.weixin.qq.com/*"]
```

也就是说，它只会在微信公众号后台页面运行，不会在其他网站注入脚本。
