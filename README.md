# WeChat MP HTML Source Helper

`WeChat MP HTML Source Helper` 是一个面向微信公众号后台编辑器的 Chrome 扩展，用来辅助导入和读取正文区域中的 HTML 内容。

扩展会在 `https://mp.weixin.qq.com/` 的图文编辑页面注入一个 `HTML 源码` 入口；当工具栏无法挂载时，会自动降级为页面右下角的悬浮按钮。

## 功能

- 在微信公众号后台编辑器中提供 `HTML 源码` 入口
- 支持粘贴 HTML 并写入当前正文编辑区
- 支持将 HTML / SVG 插入到记住的光标位置，保留前后正文与选中文字
- 支持读取当前编辑区 HTML，便于调试和排查
- 在导入前执行基础清洗，移除高风险标签和内联事件
- 自动触发常见输入事件，尽量让编辑器感知内容变更
- 阻止空内容操作；插入与覆盖前提示，当前页面可恢复最近一次操作前的正文
- 提示样式表移除、非微信图片地址和复杂布局的兼容风险
- 保留常见 SVG 图形和 SMIL 视觉动画，包括 `begin="click"`
- 仅在唯一识别到正文时允许写入；不再因 ProseMirror 类名阻止导入

## 适用范围

适合以下场景：

- 将已有 HTML 片段快速填入公众号正文
- 调试微信编辑器对某些 HTML 结构的兼容情况
- 读取当前编辑区内容做临时比对或排查

不适合以下场景：

- 复杂网页的完整无损迁移
- 依赖脚本、嵌入式组件或外部资源的内容导入
- 作为严格意义上的 HTML 安全沙箱

## 安装

当前项目以本地加载扩展的方式使用：

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角的 `开发者模式`
3. 点击 `加载已解压的扩展程序`
4. 选择目录 `wechat-html-source-extension`
5. 打开微信公众号后台图文编辑页面进行验证

## 使用方法

1. 进入 `https://mp.weixin.qq.com/` 的图文编辑页面，在正文里点击想插入的位置
2. 点击 `HTML 源码` 按钮；工具会记住打开弹窗前的正文位置
3. 在弹窗中粘贴 HTML / SVG，点击绿色的 `插入到光标位置`，阅读提示后继续
4. 插入后弹窗关闭，回到正文预览；原有文字保留。如果选中了一段文字，会在所选范围末尾插入，不删除所选文字
5. 需要整体替换时，明确点击 `替换全文`；需要读取正文时，点击 `读取当前 HTML`
6. 操作有误时，再打开工具，点击 `恢复操作前正文`；恢复也会覆盖操作后的手动修改
7. 手动保存草稿，重新打开，检查手机浅色与深色预览。扩展不会自动保存、发布或发送

SVG 和包含块级结构的 HTML 插入到段落文字中间时，会拆开该段落，将代码放在两段之间；普通行内 HTML 可直接插入文字中。也可以先在正文中按回车留出空段落，再定位并插入 SVG。

没有正文光标位置、正文在弹窗打开后发生变化、编辑区节点更换或页面地址改变时，会拒绝插入并要求重新定位；不会自动改为替换全文或追加到末尾。每次插入使用与全文替换相同的内容清洗和兼容提示。

备份仅保存在当前页面内存中，不写入本地存储或上传。只保留最近一次插入或替换前的内容，刷新/关闭页面后失效。恢复操作会核对编辑区节点和页面地址；不要将它当作跨文章历史记录。

0.2.1 已移除 0.2.0 新增的 ProseMirror 导入拦截，恢复原来的正文写入路径，同时保留备份恢复等保护。ProseMirror 可以通过 DOM 变化监听同步正文；不能仅凭编辑器名称判断导入必然失效。实际微信的结构过滤和服务器保存结果仍需保存草稿后核对。

## 安全说明

扩展在导入前会执行一层基础过滤，目前会移除以下内容：

- `script`
- `iframe`
- `object`
- `embed`
- `base`
- `meta`、`link`、`style` 和 `template`
- SVG `foreignObject`、表单及输入控件
- 所有以 `on` 开头的内联事件属性，例如 `onclick`、`onload`
- URL 属性中的 `javascript:`、`data:`、`vbscript:` 等非允许协议，以及 `srcdoc`、`srcset`
- 含危险资源引用或转义难以可靠检查的行内样式
- 可能通过 `attributeName` 改写链接、事件或样式的 SVG 动画

允许 URL 协议为 HTTP、HTTPS、mailto、tel；相对地址与页内锚点可保留。普通 SVG 图形及透明度、颜色、位移、旋转等常见动画可保留，但保留代码不代表微信一定接受。

样式表会被移除而非自动转为行内样式；图片不会自动上传到微信。此过滤用于降低明显风险，不是完整的安全沙箱或微信官方白名单复刻。

## 已知限制

- 微信公众号后台会再次清洗标签、属性和样式，最终结果可能与原始 HTML 不一致
- 工具栏 DOM 结构如果发生变化，按钮可能无法插入原位置；此时会回退到悬浮按钮
- 扩展仅在 `https://mp.weixin.qq.com/*` 范围内生效
- 当前版本不提供持久历史记录、模板管理或导出功能
- 无法唯一识别正文或识别到隐藏编辑区时拒绝写入
- 当前测试覆盖 Chromium 中的模拟编辑页，未完成真实微信公众号账号下的保存、重新打开及 iOS/Android 预览验收

## 开发

这是一个 Manifest V3 扩展，当前通过 `content_scripts` 注入脚本和样式，不依赖构建工具或第三方包。

开发时通常只需要：

1. 修改 `content.js` 或 `styles.css`
2. 回到 `chrome://extensions/` 刷新扩展
3. 重新打开或刷新公众号编辑页面验证效果

### 浏览器回归检查

运行时不需要任何依赖。测试使用 Node.js 内置测试运行器和开发用 `playwright-core`，需要 Node.js 20+ 与已安装的 Chrome：

```powershell
npm install --no-save --package-lock=false playwright-core esbuild prosemirror-model prosemirror-state prosemirror-view
node --test tests/browser.test.cjs
```

也可通过 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块目录，`CHROME_PATH` 指向 Chromium/Chrome 可执行文件，复用现有环境。`ESBUILD_MODULE` 可指定已有 esbuild 模块目录，`PROSEMIRROR_PROJECT` 可指定已安装 ProseMirror 的项目目录。以上依赖仅用于开发测试，不随扩展加载。

测试覆盖空内容、取消覆盖、备份恢复与跨编辑区拦截、编辑器识别、URL/SVG 清洗、兼容提示、iframe 事件以及键盘焦点。另使用真实 ProseMirror 验证导入/恢复后的正文数据模型，以及模型序列化后重建编辑器；该检查不等于微信服务器保存验收。

插入回归覆盖光标与选区保留、段落/行内 HTML/空段落/首尾插入、富文本格式、失效位置与标题输入框隔离、iframe 内定位、取消操作和恢复。SVG 模型检查使用显式允许 SVG 的 ProseMirror 测试 schema，不代表微信接受任意 SVG 标签或属性。

## 权限范围

当前扩展仅匹配以下页面：

```json
"matches": ["https://mp.weixin.qq.com/*"]
```

这意味着扩展不会在其他站点注入脚本。
